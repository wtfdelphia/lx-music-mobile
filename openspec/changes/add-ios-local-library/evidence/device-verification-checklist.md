前置：从「文件」App 的外部位置（如 iCloud 之外的网盘目录或
「我的 iPhone」以外的位置）添加一个含若干歌曲的文件夹，扫描完成。

| # | 操作 | 预期观察 | 结果 |
|---|---|---|---|
| 1.1 | 播放该来源一首歌，杀进程后冷启动，再播放 | 直接播放，不要求重新授权 | 通过：冷启动后直接播放，未要求重新授权 |
| 1.2 | 重启设备后播放该来源歌曲 | 直接播放 | 通过：重启后直接播放 |
| 1.3 | 用签名工具重签 ipa 并覆盖安装，播放该来源歌曲 | 沙箱路径变化后定位符仍可解析；若报授权失效，走 1.4 | 通过：SideStore 重签覆盖安装后定位符正常解析，授权未失效，未触发 1.4 |
| 1.4 | 来源管理点「重新授权」，重新选中同一目录 | 提示成功，原曲目仍在，歌单引用仍可播放（定位符不变） | 未触发：1.3 重签后授权未失效，无重新授权场景 |
| 1.5 | 重新授权时故意选中另一个目录 | 提示选错目录（E_WRONG_DIR），原授权不受影响 | 未执行：依赖 1.4 场景 |

结论：通过（依据 1.1 至 1.3）。重启、冷启动、SideStore 重签后授权均保持有效；
