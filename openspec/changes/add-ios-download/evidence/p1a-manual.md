# P1a 真机前台功能清单

> 前置：侧载 `ios-verify.yml` 产出的未签名 IPA（AltStore / SideStore 重签）。
> 首次使用需在「设置 → 下载设置」开启下载功能（会弹合规提示）。
> 逐项记录通过 / 失败 / 阻塞与现象，失败项附截图或日志。

## 功能清单

1. 搜索一首在线歌曲 → 长按（或点更多）→ 菜单出现「下载」项
2. 点「下载」→ 弹窗列出该歌曲可用音质（含大小）→ 选 128k → toast 提示已添加任务
3. 导航出现下载入口 → 下载页「全部」/「下载中」可见该任务，进度条走动
4. 下载完成 → 任务进「已完成」；「文件」App 的 `我的 iPhone › LX Music › Download` 下可见音频文件
5. 播放该歌曲（任意列表）→ 飞行模式下仍可播放（走本地文件）
6. 飞行模式下点播放栏/详情页刷新 → 回退在线失败，不影响本地播放
7. 批量：多选 3 首 → 批量弹窗固定四档 → 选 320K → 全部入队且逐首降级正确
8. 并发上限：连续下载 5 首，同时最多 3 个在跑，完成一个补位一个
9. 暂停 / 继续 / 删除 / 删除含文件：四个动作行为正确，删含文件后「文件」App 里文件消失
10. 关闭下载开关 → 导航与菜单下载项消失、运行中任务暂停；已下载歌曲仍可离线播放
11. 重新开启开关 → 任务列表保留，手动「全部开始」可继续
12. 杀进程重开 → 任务列表完整恢复，下载中的任务显示为「已暂停」
