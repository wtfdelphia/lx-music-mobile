## ADDED Requirements

### Requirement: 已下载歌曲本地优先播放

任意列表中已下载的歌曲取流时，非强制刷新情况下 SHALL 优先返回本地文件路径：先按歌曲原 id 查询下载索引，再按切源记录（`toggleMusicInfo`）id 查询，命中且文件存在即返回本地路径，不进入在线取流链路。强制刷新（播放失败重试）时跳过本地优先，回落在线并触发对账。取流路径与下载器的链接获取路径 MUST 分离，下载链接获取 MUST NOT 命中本地路径。

#### Scenario: 我的列表离线播放

- **WHEN** 飞行模式下播放「我的列表」中已下载的歌曲
- **THEN** 播放成功，走本地文件

#### Scenario: 切源歌曲命中本地

- **WHEN** 播放一首已切源的已下载歌曲
- **THEN** 按切源记录 id 命中下载索引，播放本地文件

#### Scenario: 本地文件丢失回落在线

- **WHEN** 已下载歌曲的本地文件被删除后播放
- **THEN** 回落在线取流，任务被标记文件缺失

#### Scenario: 下载器不命中本地

- **WHEN** 已下载歌曲再次创建更高音质下载任务
- **THEN** 链接获取返回在线链接，不返回本地文件路径

### Requirement: 下一首预载不探测本地文件

预载取到的链接为本地文件路径时，MUST NOT 发起网络探测，MUST NOT 因探测失败触发强制刷新重取。

#### Scenario: 本地路径预载直接通过

- **WHEN** 预载下一首已下载歌曲，取到本地文件路径
- **THEN** 不发起网络请求，预载视为可用
